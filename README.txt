QUOTESPACE — ИНСТРУКЦИЯ ПО ЗАПУСКУ
==================================

1. Что находится в папке
- index.html — структура веб-страницы.
- style.css — оформление, цвета, адаптивный дизайн.
- script.js — генерация, добавление, поиск, избранное и сохранение цитат.

2. Запуск в Windows
Самый простой способ:
1) Распакуйте архив QuoteSpace.zip в удобную папку.
2) Откройте папку QuoteSpace.
3) Дважды щёлкните по index.html.
4) Приложение откроется в браузере (Chrome, Edge или Firefox).

Для работы основных функций установка Python, Node.js или других программ не нужна.
Для загрузки шрифтов из Google Fonts требуется интернет; без него браузер использует резервные системные шрифты.

3. Как пользоваться
- «Новая цитата» / «Следующая» — показывает случайную цитату.
- Сердце — добавляет цитату в избранное или убирает из него.
- Кнопка копирования — копирует текст и автора.
- Поиск — ищет по тексту цитаты, автору и категории.
- Фильтр — показывает выбранную категорию.
- «Новая цитата» в библиотеке — прокручивает к форме.
- В форме укажите текст, автора и категорию, затем нажмите «Сохранить цитату».
- Пользовательские цитаты можно удалить значком × в карточке.
- Раздел «Избранное» открывается через левое меню.

4. Где хранятся данные
Цитаты сохраняются в localStorage браузера под ключом quotespace_data_v1.
Данные остаются в том же браузере и профиле после закрытия и повторного открытия страницы.
Очистка данных сайта/браузера может удалить сохранённые цитаты. Хранилище не синхронизируется между разными компьютерами и браузерами.

5. Если нужно открыть через локальный сервер (необязательно)
Если на компьютере уже установлен Python:
- Откройте папку QuoteSpace в Проводнике.
- Нажмите на адресную строку папки, напишите cmd и нажмите Enter.
- В открывшемся окне выполните:
  python -m http.server 8000
- В браузере откройте:
  http://localhost:8000
- Чтобы остановить сервер, вернитесь в окно командной строки и нажмите Ctrl+C.

6. Быстрая проверка перед сдачей
[ ] Главная страница открывается без ошибок.
[ ] Кнопка «Новая цитата» меняет цитату.
[ ] Можно добавить цитату с автором.
[ ] После обновления страницы добавленная цитата остаётся.
[ ] Поиск находит цитату по тексту или автору.
[ ] Фильтр по категории работает.
[ ] Сердце добавляет/убирает цитату из избранного.
[ ] Кнопка копирования работает.
[ ] Пользовательскую цитату можно удалить.
[ ] Интерфейс проверен на узком окне браузера.
